# 小宝基地 · 二次元个人导航页

一个纯静态的二次元风格个人导航主页：顶部横幅贴纸相框、站点头像、三个标签页卡片、进站弹窗、背景手绘涂鸦、自定义光标，并在页面底部展示作者与版权信息。

- 纯前端（HTML + CSS + 原生 JavaScript），无后端、无数据库
- 所有内容集中在 `config.js`，改配置即可，无需改动页面结构
- 兼容到 Windows 7 的 IE8 / IE9（自动降级），同时适配手机、平板、桌面与触屏设备

## 五、本地部署

### 方式 A：直接双击打开（最简单）

双击 `index.html` 即可。  
注意：`file://` 协议下部分接口（一言、随机图）可能因跨域或防盗链无法加载，页面会显示兜底文字 / 兜底图，属正常现象。

### 方式 B：本地静态服务器（推荐，接口可正常请求）

任选一种，在项目根目录执行：

```bash
# Python 3（Windows 自带或已安装 Python）
python -m http.server 8650 --bind 127.0.0.1

# PHP
php -S 127.0.0.1:8650

# Node.js
npx http-server -p 8650
```

然后浏览器打开 `http://127.0.0.1:8650`。

### 修改内容

1. 打开 `config.js`，修改站点名、简介、头像、标签名、卡片列表、弹窗文案、页脚作者与版权；
2. 本地图片（图标、二维码、头像）放到 `photos/`，路径填写相对路径，如 `photos/xz.png`；
3. 保存后刷新页面；若没变化按 `Ctrl + F5` 强制刷新（或递增 `index.html` 中 CSS/JS 的 `?v=` 版本号）。

## 六、云端部署

### 1. GitHub Pages（本仓库当前方式）

1. 在 GitHub 新建仓库，将本项目文件推送到 `main` 分支；
2. 仓库 **Settings → Pages**；
3. `Source` 选择 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`，保存；
4. 等待 1～2 分钟，访问 `https://<用户名>.github.io/<仓库名>/`；
5. 如需自定义域名：编辑 `CNAME` 文件为你的域名（例如 `dh.example.com`），并在域名服务商处添加 CNAME 解析指向 `<用户名>.github.io`，然后在 Pages 中勾选 `Enforce HTTPS`。

推送命令：

```bash
git add -A
git commit -m "update: 页脚居中底部 + 说明文档"
git push origin main
```

### 2. Vercel / Netlify / Cloudflare Pages

1. 注册并连接 GitHub 仓库；
2. 构建命令留空，输出目录填 `/`（纯静态项目无需构建）；
3. 部署完成后获得形如 `xxx.vercel.app` / `xxx.netlify.app` / `xxx.pages.dev` 的地址；
4. 可在平台内绑定自定义域名。

### 3. 虚拟主机 / 宝塔面板 / FTP

1. 将 `index.html`、`config.js`、`assets/`、`photos/` 上传到网站根目录（如 `wwwroot`、`public_html`）；
2. 纯静态站点无需 PHP，直接访问域名即可；
3. 若主机开启了强制 HTTPS 或默认首页设置，请确保默认首页为 `index.html`。

### 4. 自定义域名注意

- GitHub Pages 使用仓库根目录的 `CNAME` 文件控制域名；
- 换域名后记得同步修改 `CNAME`，否则 Pages 会自动重置域名设置。

## 七、浏览器兼容性

| 环境 | 表现 |
| --- | --- |
| Chrome / Edge / Firefox / Safari 新版 | 完整效果：涂鸦、光标、动画、阴影全部启用 |
| 手机 / 平板 / 触屏电脑 | 完整效果，触屏点击弹窗已专门修复 |

## 八、更新与备份建议

- **改动前先打包备份**：将整个项目目录压缩为 zip，文件名注明改动内容与日期，例如 `备份_20261119_页脚居中前.zip`；
- 修改 CSS / JS 后，把 `index.html` 中对应引用的 `?v=YYYYMMDDx` 递增一位，避免浏览器缓存旧文件；
- 页面已通过 `<meta http-equiv="Cache-Control">` 禁止缓存 HTML，仍看不到更新时按 `Ctrl + F5`。

## 九、安全说明（已移除的内容）

原模板中存在以下与功能无关的内容，本仓库已全部移除：

- 第三方网站统计脚本（会将访客数据上报到他人账户）；
- 远程加载的注入脚本（会修改页面标题、向搜索引擎主动推送链接等）；
- 对 jQuery CDN 的依赖（已改为原生 JavaScript，避免 CDN 失效或被劫持）。

当前页面除以下第三方资源外，不加载任何外部脚本：

- 小枫音乐播放器 `https://player.xfyun.club/js/xf-MusicPlayer/js/xf-MusicPlayer.min.js`（第三方，如不需要可删除 `index.html` 中对应的 `div` 与 `script`）；
- 图片 / 一言接口（仅图片与文本请求，不执行脚本）。
